User flow - investigate a threatUC-01 Log In → UC-03 Monitor → UC-04 Investigate a Threat → UC-10 Review Incidents (UC-09 email entry, UC-02 replay branch) · low-fidelity wireframes
UC-01 · Log in (steps 2-4)
Email + password. E1 invalid email, E2 one generic error, E3 lockout after 5 failures in 15 min.
UC-01 · MFA code (steps 5-6)
6-digit TOTP. E4 expires after 2 min, E5 wrong code counts towards the lockout. A3 invited users enrol here.
UC-03 · Dashboard
Health, traffic, ports, flagged events, model panel and incident timeline; time range incl. custom (E1 > 90 days).
UC-02 · Simulator (branch)
Pick a dataset, 1x/10x/100x and an attack filter; progress, pause/stop, run summary; output labelled SIMULATED.
UC-04 · Alerts (steps 1-2)
De-duplicated alerts with severity, detector, risk, first/last seen and count.
UC-04 · Alert detail (steps 3-5)
Detector + model version, grouped detections, "Why was this flagged?" (SHAP for RF, E1 if none).
UC-04 A3-A7 · Incident
AI report ("AI-generated: review before acting" / "Generated without AI"), edit as new version, merge, status + note.
UC-10 · Incident timeline (branch)
Newest first; filter by severity, status and date; E1 empty result. A1: opened from the dashboard timeline.
